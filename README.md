# The Space of Possible Bodies
### An exploration of speculative life forms and consciousness through artificial intelligence
By Marlon Barrios Solano, 2024

## Project Description
"The Space of Possible Bodies" is an interactive art installation that explores the boundaries between biological and artificial life through generative AI. The project uses Stable Diffusion to create a dynamic, evolving ecosystem of speculative organisms, visualizing potential life forms that exist at the intersection of biology, technology, and imagination.

## Technical Details
- Built with p5.js and WebGL
- Uses Stable Diffusion 3 for image generation
- Features a 3D interactive interface
- Implements real-time generative sound
- Dynamic prompt generation system
- Responsive design that adapts to different screen sizes

## Features
- Real-time generation of speculative biological entities
- Interactive 3D rotation of the visualization space
- Dynamic wireframe visualization toggle
- Custom prompt input for directed exploration
- Automatic generation of new entities every 2 seconds
- Smooth transitions and focus states
- Generative sound feedback
- Mouse-based interaction for rotation and focus

## Interaction Guide
- Click and drag to rotate the entire visualization
- Double click to reset rotation
- Press 'W' to toggle wireframe view
- Hover over images to focus them
- Use the input field to enter custom prompts
- Click the generate button to create custom entities

## Conceptual Framework
The project explores:
- Speculative evolution and biological possibilities
- The intersection of organic and synthetic life
- Emergent properties of complex systems
- The role of AI in imagining new forms of life
- The boundaries between natural and artificial

## Technical Requirements
- Modern web browser with WebGL support
- Internet connection for API access
- Audio capability for sound feedback
